# Credits

LegacyRelay incorporates or builds against the following upstream projects:

- **[Reynard Browser](https://github.com/minh-ton/reynard-browser)** — minh-ton and contributors; Gecko integration on iOS, runtime packaging and JIT implementation.
- **[Mozilla Firefox / Gecko](https://www.mozilla.org/firefox/)** — Mozilla and contributors; Gecko/GeckoView engine and runtime components.
- **[User Agent Switcher](https://addons.mozilla.org/firefox/addon/uaswitcher/)** — ntninja (ninetailed.ninja); Firefox WebExtension version 1.4.102.
- **[idevice](https://github.com/jkcoxson/idevice)** — jkcoxson and contributors; Rust library used by the sideload JIT bridge.

Original copyright and license notices are retained in the imported sources. License texts are provided in `LICENSE`, `LICENSES/`, and the corresponding upstream directories.
